# Demo video

`por-attest-demo.mp4` runs 4:00, has on-screen captions and no voice. Its frames are stills of real output captured on 1 Nov 2026. Rebuild it with `docs/video/build.py`.

To add a voice, read each caption as it appears. To replace it with a live recording, keep this order: problem, request, authoritative figures, provenance, paid call, fixtures, failures, reliability, limitations.
